AgentCo Privacy Policy

Last updated: November 10, 2026

Back to the AgentCo home page

Who this covers

AgentCo is a private tool run by one owner on the owner’s own server. It has one user: the owner.

What Google data it accesses

AgentCo asks for two Gmail permissions on one Gmail account created for it: reading messages, and creating drafts. It accesses no other Google data and does not touch the owner’s personal mailbox.

How it uses the data

Messages are read only to give the owner summaries and draft replies. Nothing is used for advertising, profiling, or selling.

How it stores the data

The access token is kept in a protected file on the owner’s own server. Message content is not copied into a public place.

Who it is shared with

Never sold or shared. The one exception: to produce a summary or draft, message text may be sent to an AI service (Anthropic’s API) and used only to return that result.

Google API Services User Data Policy

AgentCo’s use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Deletion and revoking access

The owner can revoke access at any time in the Google Account permissions page, and can delete stored data by deleting the files on the server. To ask a question or request deletion, contact: https://github.com/agentco-helper/agentco-helper.github.io/issues
